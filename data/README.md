# Public Demo Data

These CSV files are generated by the SQL workflow and are safe to use in a
public portfolio or Tableau Public workbook.

- `sql_quality_checks.csv` — validation results before analysis
- `sql_asset_daily.csv` — daily synthetic prices, returns, weights, and costs
- `sql_latest_asset_ranking.csv` — latest market-price ranking by asset
- `sql_portfolio_monthly.csv` — monthly gross/net return and cost summary
- `sql_asset_monthly.csv` — monthly allocation, contribution, and volatility
- `sql_data_dictionary.csv` — field definitions and interpretation notes
- `python_summary_metrics.csv` — compact EDA and validation summary
- `python_asset_profile.csv` — contribution and risk profile by asset
- `python_model_evaluation.csv` — baseline and model comparison
- `python_feature_importance.csv` — model feature importance for interpretation

All records are deterministic demo data. Asset names are generic, returns are
simulated, and no private Bluexprice signals or formulas are included.
